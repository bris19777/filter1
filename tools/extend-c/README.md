# ExtendC – הגדלת כונן C: לכל השטח הפנוי

`ExtendC.exe` מגדיל את מחיצת C: על כל השטח הלא-מוקצה שאחריה בדיסק.

אם בין C: לבין השטח הפנוי יושבת מחיצת שחזור של Windows (מה שחוסם את "הרחב אמצעי אחסון" בניהול דיסקים), הכלי:
1. מעביר זמנית את סביבת השחזור (WinRE) לכונן C: (`reagentc /disable`) ומוודא ש-`Winre.wim` קיים.
2. מוחק את מחיצת השחזור הישנה.
3. מגדיל את C: עד סוף הדיסק פחות 1 GB.
4. יוצר מחיצת שחזור חדשה בגודל 1 GB בסוף הדיסק.
5. מפעיל מחדש את סביבת השחזור (`reagentc /enable`).

לפני כל שינוי מוצג סיכום של מה שנמצא ומה יבוצע, ונדרש אישור. הכלי לא נוגע במחיצות אחרות; אם אחרי C: יש מחיצה שאינה מחיצת שחזור, הוא עוצר בלי לשנות כלום.

לוג: `%TEMP%\ExtendC\ExtendC-log.txt`

## בנייה (Linux)
```bash
sudo apt-get install -y gcc-mingw-w64-x86-64
./build.sh
```
