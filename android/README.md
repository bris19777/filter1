# filter1 — סוכן אנדרואיד (DNS)

סוכן אנדרואיד שמדבר עם **אותו שרת בקרה** של הגרסה ל-Windows. המכשיר מופיע בלוח
הבקרה כמכשיר נוסף, ומקבל את אותם ארבעה מצבים (`open` / `lockdown` / `blacklist` /
`whitelist`), רשימות לבנות/שחורות והקטגוריות, דרך `GET /api/config`.

האכיפה היא **ברמת ה-DNS** באמצעות `VpnService` מקומי: כל שאילתת DNS עוברת דרך הסוכן,
נחסמת (מחזיר `0.0.0.0`) או מועברת ל-upstream. אין סינון תוכן HTTPS (MITM) באנדרואיד,
כי מאנדרואיד 7 אפליקציות מתעלמות מתעודת שורש שהמשתמש מוסיף.

> סטטוס: קוד ייחוס. **לא נבנה/נבדק בסביבה הזו** — יש לבנות ב-Android Studio ולבדוק
> על מכשיר. חלק פענוח/בניית מנות ה-DNS הוא החלק שהכי סביר שידרוש כוונון על מכשיר אמיתי.

## מבנה

```
android/
  app/src/main/java/com/bsd/filter1/
    MainActivity.kt      מסך: כתובת שרת + טוקן, הפעל/כבה
    FilterVpnService.kt  ה-VpnService: לולאת tun, פענוח DNS, חסימה/העברה
    Poller.kt            משיכת קונפיג כל דקה והחלתו
    ServerClient.kt      קריאה ל-/api/config + הורדת רשימות ציבוריות
    Policy.kt            מצב המדיניות + החלטת חסימה (התאמת תת-דומיינים)
    Prefs.kt             שרת, טוקן, device_id יציב, דגל הפעלה
    BootReceiver.kt      הפעלה מחדש אחרי אתחול
    AdminReceiver.kt     Device Owner: always-on VPN, חסימת הסרה
```

## בנייה

1. פתח את תיקיית `android/` ב-Android Studio (או `./gradlew :app:assembleDebug`).
2. בנה APK. התקן על המכשיר.
3. באפליקציה: הזן את כתובת השרת (ברירת מחדל `https://bsd-filter1.fly.dev`) ואת הטוקן,
   ולחץ "הפעל הגנה". אשר את בקשת ה-VPN של אנדרואיד.

## עמידות (Device Owner) — אופציונלי אך חיוני לאכיפה אמיתית

בלי Device Owner המשתמש יכול לכבות את ה-VPN או להסיר את האפליקציה. כדי להפוך אותה
לעמידה (המקבילה לשירות ה-SYSTEM ב-Windows):

1. אפס את המכשיר להגדרות יצרן ואל תוסיף חשבון Google בהגדרה.
2. התקן את ה-APK (למשל `adb install app.apk`).
3. הגדר Device Owner:
   ```
   adb shell dpm set-device-owner com.bsd.filter1/.AdminReceiver
   ```
4. מרגע זה `AdminReceiver` מפעיל אוטומטית: **Always-on VPN עם Lockdown** (אין אינטרנט
   בלי הסוכן), **חסימת הסרה** של האפליקציה, ומניעת הגדרת VPN אחר / Safe Mode / איפוס.

## מה עובד ומה לא

- **עובד:** סינון DNS לכל האפליקציות, ארבעת המצבים, רשימות וקטגוריות מהשרת, מזהה מכשיר
  יציב, דיווח מצב, הפעלה מחדש באתחול, ועמידות מלאה תחת Device Owner.
- **מגבלות:**
  - IPv4 בלבד בשלב זה (השאילתות מנותבות ל-`10.0.0.2`). IPv6 אפשר להוסיף בהמשך.
  - אין סינון HTTPS לפי תוכן (ראה למעלה).
  - VPN שמתחבר ל-IP גולמי או DoH ייתכן שיעקוף; עמידות מלאה דורשת Always-on Lockdown
    (Device Owner) שמכריח את כל התעבורה דרך הסוכן.
  - סלולר/רשת אחרת לא מושפעים מהמיקרוטיק, אבל הסוכן עצמו פועל על המכשיר בכל רשת.

## אינטגרציה עם השרת

אין צורך בשינוי שרת. הסוכן משתמש ב-`/api/config` הקיים ובאותו טוקן. אם תרצה שהטלפון
יופיע בנפרד בלוח הבקרה, הוא כבר שולח `device_id` ו-`name` ייחודיים.
