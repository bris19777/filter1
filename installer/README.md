# מתקין הכל-באחד ל-Windows

קובץ התקנה יחיד, `filter1-setup.exe`, שמכיל **הכל**: פייתון פרטי, dnslib,
mitmproxy, שני הסוכנים ותוסף הסינון. אין שום הורדה מהאינטרנט בזמן ההתקנה.
לחיצה כפולה מתקינה גם את שכבת ה-DNS וגם את הפרוקסי, כולל התעודה, המדיניות וחומת האש.

## איך בונים אותו

הבנייה רצה על שרת Windows של GitHub, אין צורך במחשב Windows משלך.

1. דחוף את הפרויקט ל-GitHub.
2. בהגדרות המאגר, תחת **Settings → Secrets and variables → Actions**, הוסף:
   - **Secret** בשם `AGENT_TOKEN` עם ערך הטוקן שלך.
   - אופציונלי, **Variable** בשם `FILTER1_SERVER` אם כתובת השרת שונה מברירת המחדל.
3. בלשונית **Actions**, הרץ את **Build installer** ידנית (Run workflow), או דחוף תג גרסה כמו `v1.1.1`.
4. בסיום, הורד את הפריט `filter1-setup` שמכיל את `filter1-setup.exe`.

## התקנה על מחשב לקוח

לחיצה כפולה על `filter1-setup.exe`. תופיע אזהרת SmartScreen כי הקובץ לא חתום —
לחץ **More info → Run anyway**. ההתקנה מתקינה את שתי השכבות ומפעילה אותן.

## הסרה

דרך **הוספה והסרה של תוכניות → filter1 → Uninstall**. ההסרה **מבקשת את קוד ההסרה**
מלוח הבקרה, מאמתת אותו מול השרת, ורק אז מסירה הכל ומחזירה את המערכת לקדמותה.
בלי קוד נכון ההסרה נעצרת.

## הערות

- **חתימת קוד:** הקובץ לא חתום, ולכן SmartScreen יזהיר. להסרת האזהרה צריך תעודת חתימה בתשלום.
- **גודל:** הקובץ גדול, עשרות מגה, כי הוא מכיל פייתון ו-mitmproxy מלאים.
- **טוקן:** הטוקן מוטמע בתוך הקובץ. שמור אותו אצלך ואל תפיץ אותו בפומבי.
