# קליינט filter1 ל-Windows

התקנה של הסוכן על מחשב לקוח (Windows x86/x64). ההתקנה נעשית פעם אחת על ידי ההורה,
עם הרשאות מנהל. הסוכן מייצר מזהה מחשב אוטומטית ונרשם בשרת הבקרה תוך דקה.

## דרישה מקדימה

השרת חייב להיות נגיש מהאינטרנט (כתובת ציבורית), לא `localhost`. מחשב הלקוח מתחבר אליו
דרך האינטרנט. פרוס את השרת ל-Fly.io או Render (ראה README הראשי), וקח את הכתובת שלו.

## התקנה

1. העתק את התיקייה `agent` כולה (כולל `agent.py` ותיקיית `windows`) למחשב הלקוח.
2. פתח את `windows\install.ps1` בעורך טקסט ומלא שני שדות בראש הקובץ:
   - `$Server` — כתובת השרת הציבורית, למשל `https://filter1.fly.dev`
   - `$Token`  — אותו ערך של `AGENT_TOKEN` שהגדרת בשרת
3. לחיצה ימנית על `install.bat` ובחירה ב-**Run as administrator**.

הסקריפט:
- מתקין Python אם חסר (דרך winget), ואת ספריית `dnslib`.
- מעתיק את הסוכן ל-`C:\Program Files\filter1\` וכותב קובץ הגדרות.
- רושם משימת מתוזמנת בשם `filter1` שרצה בהפעלת המחשב תחת חשבון SYSTEM,
  עם הרשאות גבוהות והפעלה-מחדש-בכשל.
- מפעיל את הסוכן מיד.

אחרי ההתקנה המחשב יופיע בלוח הבקרה. משם תבחר לו מצב ורשימות.

## איך זה אוכף

הסוכן מריץ שרת DNS מקומי על `127.0.0.1`, מכוון אליו את ה-DNS של כרטיס הרשת, ומוודא זאת
כל 30 שניות. שאילתה לדומיין חסום מקבלת `0.0.0.0` והדפדפן לא מגיע לאתר. במצב "חסימה מלאה"
או "רשימה לבנה" רק הדומיינים שאישרת נפתרים.

## הסרה

לחיצה ימנית על `uninstall.bat` -> Run as administrator. הסקריפט מבקש את **קוד ההסרה**
שמופק בלוח הבקרה (כפתור "הפק קוד הסרה"), מאמת אותו מול השרת, ורק אז מסיר את המשימה,
מחזיר את ה-DNS לאוטומטי, ומוחק את הקבצים. בלי הקוד הנכון ההסרה נעצרת.

## מגבלות ידועות

- אכיפת ה-DNS חוסמת לפי דומיין. אתר שנגלש דרך IP ישיר או דרך VPN/DNS-over-HTTPS בדפדפן
  עשוי לעקוף. לחסימה חזקה יותר אפשר בעתיד לחסום פורטי DNS חיצוניים ו-DoH ידועים בחומת האש.
- הכלי שקוף: המשימה `filter1` מופיעה ב-Task Scheduler בשמה האמיתי.
