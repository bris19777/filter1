# הקשחת מחשב Windows נגד עקיפה

הסוכן חוסם ברמת ה-DNS ומכבה DNS מוצפן בדפדפנים. אבל את העקיפה החזקה ביותר, VPN,
אי אפשר לעצור לגמרי ברמת הרשת. הצעד היחיד שבאמת עוצר אותה הוא **חשבון משתמש בלי הרשאות מנהל**.

## 1. חשבון רגיל לילד (הכי חשוב)

בלי הרשאות מנהל הילד לא יכול להתקין VPN, לשנות DNS, לכבות את השירות, או לגעת בחומת האש.

1. היכנס כמנהל. פתח **הגדרות → חשבונות → משתמשים אחרים** (או `netplwiz`).
2. ודא שיש חשבון מנהל אחד עם סיסמה חזקה שרק אצל ההורה.
3. את החשבון של הילד הגדר כ-**Standard User** (משתמש רגיל), לא מנהל.
4. ודא שאין לילד את סיסמת המנהל.

מרגע זה, כל ניסיון להתקין תוכנה או לשנות הגדרות רשת יבקש את סיסמת המנהל.

## 2. מה שהמתקין כבר עושה אוטומטית

- שירות סינון DNS שרץ כ-SYSTEM עם הפעלה מחדש בכשל.
- כיבוי DNS מוצפן (DoH) בכרום, אדג' ופיירפוקס, כולל הפיכת ההגדרה ללא-נגישה.
- כללי חומת אש שחוסמים פרוטוקולי VPN נפוצים: WireGuard, OpenVPN, IKEv2, PPTP, L2TP.
- **חסימת הרצה של תוכנות VPN מוכרות** (ProtonVPN, NordVPN, ExpressVPN, OpenVPN,
  WireGuard, Windscribe, Surfshark ועוד) דרך Image File Execution Options.
  החסימה לפי שם קובץ ההרצה, בלי תלות בנתיב ההתקנה. ניתן לעקוף בשינוי שם הקובץ,
  ולכן צריך גם את שכבה 3 או חשבון רגיל.

## שכבה 3 (אופציונלי) — חומת אש "ברירת מחדל חסום"

חוסמת את **כל** התעבורה היוצאת חוץ מרשימת אפליקציות מאושרות (דפדפנים, הסוכן, ורכיבי
Windows חיוניים). כך כל VPN, גם אם שונה שמו וגם במצב Stealth על 443, לא מצליח לצאת
לרשת כי הוא לא ברשימה.

**אזהרה:** זו שכבה חזקה. הרץ אותה על מחשב שאתה יכול להגיע אליו, ובדוק. אם משהו שאתה
צריך מאבד אינטרנט, הרץ את הביטול מיד.

- הפעלה: לחיצה ימנית על `harden-firewall.bat` → Run as administrator.
- ביטול: לחיצה ימנית על `unharden-firewall.bat` → Run as administrator.

אם אפליקציה מותרת חסרה ברשימה (למשל דפדפן אחר או תוכנה לגיטימית), ערוך את
`harden-firewall.ps1` והוסף את הנתיב שלה לרשימת ה-`$allow`, ואז הרץ שוב.

## 3. מגבלה שכדאי להכיר

ל-ProtonVPN ולחלק מה-VPN יש מצב "Stealth" שמתחפש לתעבורת HTTPS רגילה על פורט 443.
אי אפשר לחסום אותו לפי פורט בלי לשבור את כל הגלישה. לכן שילוב של חומת האש **וחשבון בלי
הרשאות מנהל** הוא מה שנותן הגנה אמיתית: החשבון הרגיל מונע מלכתחילה את ההתקנה של ה-VPN.

## 4. אם כבר מותקן VPN במחשב

הסר אותו כמנהל לפני שמורידים את החשבון של הילד לרגיל:
לוח הבקרה → הוספה/הסרה של תוכניות → הסר את ProtonVPN וכל VPN אחר.
