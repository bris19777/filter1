# filter1 — שכבת יירוט TLS מלא (mitmproxy)

השכבה המתקדמת והחזקה ביותר. מסננת HTTPS לפי שם אתר גם מול DoH ו-ECH, כי הפרוקסי
מסיים את ה-TLS ורואה את התוכן המפוענח. זו הגישה שנטפרי וכלים מסחריים משתמשים בה.

בנוי על **mitmproxy**, כלי בוגר ומבוקר, לא על קוד יירוט שנכתב מאפס. תוסף הסינון
`filter_addon.py` מתחבר לאותו שרת בקרה, ומחיל את אותם מצבים ורשימות כמו סוכן ה-DNS.

## אזהרות — חובה לקרוא

- **רק על מחשבים שאתה מנהל.** הפרוקסי רואה את כל תעבורת ה-HTTPS בטקסט גלוי, כולל סיסמאות.
- **Certificate pinning** — אפליקציות כמו בנקאות, וואטסאפ, וחלק משירותי גוגל/מיקרוסופט
  ינעלו תעודה וישברו. צריך להחריג אותן (ראה למטה).
- **בדוק על מחשב אחד** שאתה יכול להגיע אליו פיזית לפני פריסה רחבה. שמור את `uninstall-proxy.bat` בהישג יד.
- דורש שסוכן ה-DNS כבר מותקן, כי הפרוקסי משתמש ב-`filter1.cfg` וב-`device_id` שלו.

## התקנה

1. התקן קודם את סוכן ה-DNS (שורת ה-irm הרגילה).
2. העתק את תיקיית `proxy` למחשב.
3. לחיצה ימנית על `install-proxy.bat` → Run as administrator.

מה שהוא עושה: מתקין mitmproxy, מייצר ומתקין תעודת שורש, מכריח את המחשב דרך הפרוקסי
המקומי `127.0.0.1:8080` לכל המשתמשים ונועל את ההגדרה, חוסם QUIC כדי שכלום לא יברח על
UDP 443, ומריץ את mitmdump כשירות SYSTEM עם תוסף הסינון.

## החרגת אפליקציות שנשברות (pinning)

אם אפליקציה לגיטימית מפסיקה לעבוד, החרג את שם המארח שלה כך שהפרוקסי יעביר אותה בלי לפענח.
ערוך את המשימה `filter1-proxy` והוסף לארגומנטים של mitmdump:

```
--ignore-hosts "(^|\.)(bank\.co\.il|web\.whatsapp\.com)$"
```

אפשר להוסיף כמה מארחים מופרדים ב-`|`. שים לב שמארח מוחרג לא מסונן.

## הסרה

לחיצה ימנית על `uninstall-proxy.bat` → Run as administrator. מסיר את השירות, מכבה
ומשחרר את הפרוקסי, מחזיר QUIC, ומסיר את תעודת השורש.

## מגבלה שנשארת

גם עם יירוט מלא, מה שבאמת מחזיק את זה הוא **חשבון בלי הרשאות מנהל**. משתמש עם הרשאות
מנהל יכול להסיר את התעודה, לכבות את הפרוקסי, או להסיר את השירות. ראה `agent/windows/hardening.md`.
