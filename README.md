# filter1 — בקרת הורים מבוססת DNS עם שליטה מרחוק

כלי בקרת הורים **גלוי** למחשב Windows x86. ההורה (מנהל המחשב) מתקין אותו, מכיר אותו,
ושולט בו מרחוק דרך ממשק ווב בעברית. הכלי אינו נסתר מהמשתמש ואינו מתחמק מזיהוי — הוא רק
עמיד בפני כיבוי מזדמן, בדיוק כמו Microsoft Family Safety או Qustodio.

## איך זה עובד

שני חלקים:

1. **שרת בקרה (ענן)** — `server/app.py`. אפליקציית Flask עם ממשק ווב בעברית (RTL).
   שומר את המצב הנוכחי ואת הרשימות ב-`data/config.json`, ומגיש אותם לסוכן דרך API מאובטח בטוקן.
2. **סוכן (על ה-PC)** — `agent/agent.py`. מריץ שרת DNS מקומי ב-`127.0.0.1:53`, קובע אותו
   כ-DNS של המערכת, מושך את הקונפיג מהשרת כל דקה, ומסנן כל שאילתת DNS לפי המצב.

האכיפה היא ברמת ה-DNS: אם דומיין חסום, השאילתה מקבלת תשובת חסימה (`0.0.0.0`) והדפדפן לא מגיע לאתר.

## ריבוי מחשבים

כל סוכן מייצר בהפעלה הראשונה **מזהה מחשב** יציב (`device_id`) ושומר אותו מקומית
(ב-Windows: `C:\ProgramData\filter1\device_id`). בכל פנייה לשרת הוא שולח את המזהה ואת שם
המארח. השרת רושם מחשב חדש אוטומטית עם הגדרות ברירת המחדל, ומרגע זה הוא מופיע בלוח הבקרה.

בלוח הבקרה רואים רשימת מחשבים עם חיווי מחובר/מנותק והמצב הנוכחי של כל אחד. לחיצה על מחשב
פותחת מסך שליטה נפרד: מצב, רשימה לבנה וחסימות ידניות לאותו מחשב בלבד. מקורות הרשימות
הציבוריות משותפים לכל המחשבים.

## ארבעת המצבים

| מצב | קוד | התנהגות |
|-----|-----|---------|
| הכל מותר | `open` | העברה שקופה לשרת DNS ציבורי (1.1.1.1) |
| חסימה מלאה | `lockdown` | פותר רק דומיינים ברשימה הלבנה + שרת הבקרה. כל השאר חסום |
| רשימה שחורה | `blacklist` | חוסם רשימות ציבוריות (StevenBlack/HaGeZi) + חסימות ידניות. השאר מותר |
| רשימה לבנה | `whitelist` | פותר רק דומיינים ברשימה הלבנה. השאר חסום |

שינוי מצב או רשימה בממשק הווב מתעדכן אצל הסוכן תוך עד דקה.

## עמידות בפני הסרה (לגיטימית, שקופה)

- הסוכן רץ כ**שירות Windows** עם הפעלה אוטומטית והרשאות SYSTEM.
- **ריאסרט DNS**: כל 30 שניות הסוכן מוודא שה-DNS של המערכת עדיין מצביע אליו. אם שינו — מחזיר.
- **פעולות כשל בשירות** (`sc failure`): השירות מופעל מחדש אוטומטית אם נעצר.
- **הסרה דורשת סיסמת הורה** דרך ממשק הווב (מייצר קוד הסרה חד-פעמי).

הכל שקוף: השירות מופיע ברשימת השירותים בשמו האמיתי, אין הסתרה.

## הרצה מקומית לפיתוח

שרת:
```
cd server
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5055
```

סוכן (דורש הרשאות מנהל ל-DNS; להרצת בדיקה בלבד):
```
cd agent
pip install -r requirements.txt
python agent.py --server http://127.0.0.1:5055 --token DEV --once
```

## פריסה בענן

- שרת: Fly.io או Render, כמו bsd-invoices. משתני סביבה: `PARENT_PASSWORD`, `AGENT_TOKEN`, `SECRET`.
- סוכן: נבנה ל-exe עם PyInstaller ומותקן כשירות (ראה `agent/install.md`).

## מבנה

```
server/   שרת הבקרה (Flask + ממשק ווב)
agent/    הסוכן ל-Windows (פרוקסי DNS + poller + הקשחה)
proxy/    שכבת יירוט TLS מלא עם mitmproxy (מתקדם, אופציונלי)
```

## שכבות אכיפה

1. **סינון DNS** (agent) — חוסם לפי דומיין. עוקף על ידי DoH/ECH.
2. **כיבוי DoH + חסימת VPN + חסימת הרצת VPN** (agent, אוטומטי).
3. **חומת אש ברירת-מחדל-חסום** (agent/windows/harden-firewall, אופציונלי).
4. **חשבון בלי הרשאות מנהל** (ידני, הכי חשוב).
5. **יירוט TLS מלא** (proxy, מתקדם) — סינון HTTPS לפי אתר גם מול DoH/ECH.
